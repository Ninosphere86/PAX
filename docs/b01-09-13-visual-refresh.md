# B01_09—B01_13 写实学习封面图刷新

## 统一提示词

- 用途：新能源汽车驾驶理论学习题的 16:9 写实封面图。
- 风格：自然光、纪实摄影、真实中国驾驶环境和无品牌新能源小型乘用车。
- 记忆设计：一张图只表达一个动作顺序或安全结论，关键文字只出现一次。
- 准确性：区分行驶、预热、检查电量、装备灭火器和雨雪充电防水五类场景。

## 逐题画面设计

| 题号 | 单图记忆场景 | 关键准确性要求 |
| --- | --- | --- |
| B01_09 | 初次驾驶新能源车时由教练明确提示禁止动作 | 安全车速、大车距；唯一文字“不要急加速、急减速” |
| B01_10 | 冬季为画面中唯一一辆待充电汽车进行电池预热 | 车身只有一个正常且为空的充电口，充电枪仍在该车旁的充电桩上；唯一文字“本车先预热” |
| B01_11 | 出发前在静止车辆内检查剩余电量 | 车辆仍在停车位，唯一文字“剩余电量 80%” |
| B01_12 | 出发前在后备厢固定新能源车专用灭火器 | 唯一文字“专用灭火器”，不表现火灾事故 |
| B01_13 | 雨雪天气在遮雨棚下给充电口安装防水罩 | 插头完全连接、防水罩包覆接口；唯一文字“充电口防水” |

最终图片保存在 `public/question-images-ai/`。本轮重做的 B01_09、B01_10 使用 `-v3.webp` 文件，B01_11—B01_13 沿用 `-v2.webp`；原始图片继续保留，便于回滚和对比。
