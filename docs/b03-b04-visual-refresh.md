# B03、B04 写实学习封面图刷新

## 统一提示词

- 用途：驾驶理论学习题的 16:9 写实封面图，以一个连贯真实场景帮助理解和记忆。
- 风格：参考用户提供的中国城市道路照片，采用自然光、纪实摄影、真实人物与车辆比例。
- 构图：主体在小程序尺寸下仍可辨认；避免拼贴、分屏、信息图和无关装饰。
- 文字：仅在数字、期限或车型代号是核心考点时保留一处关键文字，不同时呈现错误选项。
- 准确性：逐题锁定人物年龄、动作、道路类型、车道数量和车辆类别；不出现品牌、商标或水印。
