# 科四场景类 C03 导入记录

## 来源与范围

- 来源文档：`科目四场景题_终版.docx`
- 新增分类：`科四场景类-C`
- 新增章节：`C03`
- 新增题目：`C03_01` 至 `C03_05`，共 5 道单选题
- 题干、选项、答案、简析和详解均从文档结构化提取；正文答案与答案速查表逐题一致。

## 图片重制

5 张题图均使用内置 ImageGen 重新生成，未沿用 Word 内的动画截图。项目内最终图片保存在：

- `public/question-images/c03-01-v2.webp`
- `public/question-images/c03-02-v2.webp`
- `public/question-images/c03-03-v2.webp`
- `public/question-images/c03-04-v2.webp`
- `public/question-images/c03-05-v2.webp`

统一规格为 1280 × 720 WebP。Prompt set 使用 `photorealistic-natural`，统一约束为中国右侧通行、车道与车辆方向准确、单场景、16:9、移动端可辨识、无水印，并分别强化以下主题：

1. 拥堵时减速停车并依次排队。
2. 本车道遇障碍且对向来车临近时平稳停车让行。
3. 经过右侧停放车辆时减速并预留横向安全距离。
4. 山区盲弯减速、鸣喇叭、靠右行。
5. 高速拥堵时 A 车占用应急车道属于错误行为。

## 校验

- 5 道题编号连续且无重复。
- 5 道题均有题图、选项、答案、简析和详解。
- 图片逐张检查了人车数量、道路方向、车道线、车辆位置和动作表达。
- 站点在已有共享题库快照存在时，会只补入缺失的 `科四场景类-C` 内置题；后续编辑和删除仍由共享覆盖记录控制。
