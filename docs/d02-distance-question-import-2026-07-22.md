## 图片重制

全部 46 道题均配有新题图，包括文档中原本没有图片的 20 道题。图片使用内置 ImageGen 的 `photorealistic-natural` 模式生成，统一保存为：

`public/question-images/d02-01-v2.webp` 至 `public/question-images/d02-46-v2.webp`

统一规格为 1280 × 720 WebP。Prompt set 分为以下场景：

1. 安全跟车距离、车速变化、湿滑路面、坡道、山区和雾天。
2. 堤坝、村庄、渡口、铁路道口、事故易发、避险车道等警告标志。
3. 停车检查、停车场、出口、入口、收费站、加油站和服务区等距离标志。
4. 高速公路车距确认线、50/100/150/200 米距离规则和低能见度规则。
5. 隧道、故障停车、紧急制动及准驾车型场景。

所有图片统一要求中国右侧通行、车道与车辆方向准确、距离数字和箭头可辨、单场景、无水印。26 张 Word 原图只作为标志内容参考，未作为最终题图使用。`D02_13`、`D02_14` 经过二次生成，确保铁路道口距离牌分别为两道和三道红色斜杠。
