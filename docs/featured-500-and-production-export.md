# 科目一精选 500 与生产导出说明

更新日期：2026-07-22

## 科目一精选 500

题库工具左侧原“随机组卷”已改为“精选500”。精选范围只包含科目一已发布题目，不包含科目四。

当前精选规则：

1. 按科目一现有 49 个章节的题量比例分配名额，保证所有章节均有覆盖；
2. 在每个章节内综合题干、选项、简析和详解，计算中文三字片段相似度；
3. 采用最远点抽样优先保留内容完整且相互差异较大的题目，降低同一考点的重复表达；
4. 最终固定为 500 道，可复现、可审核，不会因每次点击而随机变化。

精选清单位于 `app/featured-500.json`，重新生成命令为：

```bash
python3 scripts/build_featured_500.py
```

## 生产文件导出

工具顶部提供两个相互配套的生产导出：

- `一键导出最终 JSON`：下载 `QuestionBank.json`；
- `导出全部图片 ZIP`：下载 `QuestionBankImages.zip`。

图片压缩包内采用扁平结构，文件名与 JSON 的“题目内容 → 图片”字段严格一致，例如：

```text
QuestionBankImages.zip
├── B01_01.webp
├── B01_02.webp
├── …
└── I05_220.webp
```

即使多道题复用同一张源图，压缩包也会按各自题目编号生成独立文件，确保服务器按 JSON 文件名直接读取。没有图片的题目在 JSON 中图片字段为空，压缩包不生成空文件。

当前压缩包包含 1,922 张题图，总大小约 81.7 MB。网站构建阶段会预生成标准 ZIP，并拆成 4 个小于 25 MB 的传输分片；点击导出后浏览器顺序读取分片并直接写入同一个 `QuestionBankImages.zip`。支持文件流写入的浏览器不会把整包放进页面内存，从而避免前端同时读取上千张图片造成页面或 Codex 崩溃。

重新生成命令为：

```bash
npm run build:images
```

常规 `npm run build` 会先自动刷新图片压缩包，再构建网站。

## 服务器更新流程

1. 从题库工具下载最新 `QuestionBank.json`；
2. 下载同版本 `QuestionBankImages.zip`；
3. 将 JSON 上传到小程序服务器现有题库 JSON 位置；
4. 将 ZIP 解压到小程序服务器现有题图目录，保持压缩包内文件名不变；
5. 抽查 JSON 中若干“图片”字段，确认服务器题图目录内存在同名文件。

这两个文件应作为同一版本一起发布，避免 JSON 已更新而图片仍是旧版本。
