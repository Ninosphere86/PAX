# 题库图片审图标准

本标准适用于科目一、科目四全部题库图片，以及新图、重做图和批量替换图。审图以“准确表达考点，并能在手机上快速看懂”为目标。

## 一、主题必须突出

- 题目主题所描述的人、车、道路、标志、动作或结果，必须是画面中最明显的主体，或构成整张图最显著的表意。
- 用户应能在约 3 秒内说出画面表达的核心内容，不依赖题干补充说明，也不需要在画面中寻找关键对象。
- 构图、景别、光线、对比度和主体大小都应服务于考点。无关人物、车辆、建筑和装饰不得抢占视觉中心。
- 一张图优先表达一个核心考点。若画面同时出现多个对象，必须通过位置、大小、视线或动作关系明确主次。

以下情况不通过：

- 主题对象只占画面很小的局部。
- 背景或无关对象比考点更醒目。
- 画面看起来合理，但第一眼无法判断它与题目考点的关系。
- 需要阅读图片中的小字、寻找角落细节或依靠题干猜测，才能理解图片。

## 二、必须适合手机尺寸观看

- 审图除查看原图外，必须同时查看约 360px 宽的手机预览；不得只根据电脑大图判断。
- 答题或判断所依赖的关键信息必须在手机预览中仍然清晰，包括车辆身份、人物动作、车道位置、道路标线、交通标志、灯光状态、距离数字和关键中文。
- 如果答案依据位于画面局部，应通过放大主体、简化背景、调整景别或重构构图，使用户无需缩放即可辨认。
- 精确数字和必要文字使用确定性叠加，字号、颜色和对比度必须保证手机端一眼可读。

以下情况不通过：

- 必须放大图片才能看到答案依据。
- 关键车辆、标志、车灯、证件或人物动作在手机上无法区分。
- 关键信息依赖过细的线条、过小的文字、过弱的明暗差异或容易混淆的局部细节。
- 电脑端看起来正确，但缩小后主题消失或判断依据丢失。

## 三、内容必须准确

- 逐字核对题干、答案和解析，确认人物身份、车型、车辆数量、行驶方向、车道关系、道路类型、标志位置、距离和动作均与题意一致。
- 中国道路场景遵守右侧通行；车道宽度、应急车道位置、标线和车辆占道关系必须合理。
- 不得为了视觉效果增加会改变答案、造成歧义或与法规相冲突的元素。
- 图片中的中文、数字、道路标识和划线必须准确；生成模型无法可靠完成的内容应后期确定性制作。

## 四、固定审图顺序

1. **题意核对**：逐项列出题干中的人、车、道路、动作、数字和判断依据。
2. **3 秒主题测试**：第一眼能否看出核心考点，主题是否为最显著内容。
3. **手机预览测试**：缩至约 360px 宽，不放大检查关键判断信息。
4. **交通准确性检查**：核对车型、方向、车道、标线、距离、灯光和标志。
5. **干扰项检查**：确认没有抢主题、改变答案或造成误解的内容。

只有五项全部通过，图片才能标记为 `approved`；任意一项不通过，标记为 `redo` 并写明具体问题。

## 五、审图反馈格式

反馈必须说明“哪张图、哪个关键点、手机上哪里看不清或表意哪里不准”，例如：

```text
M01_01：临时牌照占比太小，手机上无法看清，需把临牌作为画面主体。
M01_02：150米是判断依据，手机上必须直接可见，不能依赖细小透视距离。
B01_10：无法一眼确认是哪辆车需要充电，需突出目标车辆和充电关系。
```
