## 1. 命名原则

1. 先聚类、再编码：先按知识领域归入大类，再使用有记忆点的英文字母作为大类代码。
2. 子类使用两位数字：同一大类下按 `01`、`02`、`03` 顺序扩展。
3. 题号与分类一一对应：完整题目编号格式为 `大类字母 + 两位子类 + 下划线 + 题序`，例如 `B01_01`、`C03_06`、`I05_220`。
4. 编码稳定优先：已经投入使用的编号不因分类名称微调而重复占用或随意回收。
5. 新增子类应在所属大类内顺延编号，并同步更新题库、题图文件名、导出 JSON 和本规范。

## 5. 历史编码迁移

| 历史分类/编号 | 现行分类/编号 | 处理规则 |
| --- | --- | --- |
| 科四酒驾类-A / A01 | 科四场景类-C / C01 | 题序、内容、答案、解析、图片和稳定 ID 保持不变 |
| 科四距离类-D / D02 | 科四场景类-C / C02 | 题序、内容、答案、解析、图片和稳定 ID 保持不变 |
| 原科四场景类-C / C03 | 科四场景类-C / C03 | 原 C03_01–C03_05 保留 |
| 科四记分题 L02_01 | 科四场景类-C / C03_06 | 作为综合场景题追加，不建立 C04 |

页面读取历史共享快照时，会自动把旧 A01、D02 分类映射为 C01、C02，防止旧记录重复或历史编辑丢失。

## 6. 新增题目执行规则

1. 先确定科目和大类，再确定子类编码。
2. 在对应子类内使用下一个可用题序，不跨类复用编号。
3. 题图文件名与题号保持对应，例如 `C03_06` 使用 `c03-06-v2.webp`。
4. 题目正文、答案、选项和答案速查表必须交叉校验。
5. 分类调整时，优先保留底层稳定 ID；显示题号、章节、标签和导出编号同步更新。
6. 每次新增或迁移后，更新本知识库文档中的题量与迁移记录。
