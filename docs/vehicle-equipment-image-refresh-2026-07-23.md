## 视觉与准确性原则

- 使用 16:9 写实图，按小程序约 375px 显示宽度检查可辨识度。
- 设备位置、按钮状态、踏板数量、方向盘拨杆方向和人物坐姿必须与题意一致。
- 仪表题严格保留指针、数字、颜色、图标朝向以及选择题排列。
- 选择题标签按原图保留：原图使用 `图1—图4` 时不得改成 `A—D`，反之亦然。
- 左右转向按车辆物理方向判断，不按画面左右猜测。
- 雾灯、近光、远光、示廓灯和危险报警闪光灯分别核对灯型、颜色和作用场景。
- 会车、跟车、超车、临时停车等题目同时核对车辆方向、相对位置和灯光状态。

## 生成与切换方式

图片使用 Codex 内置 ImageGen 生成或精确编辑，再统一转换为 `1280 × 720`、JPEG 品质 84。题库切换由以下命令一次性完成：

```bash
python3 scripts/build_vehicle_equipment_image_prompts.py --apply
```

脚本会先确认 127 个目标文件全部存在，再将 172 道题映射到新版图片，并重建图片 ZIP 导出清单。
